# Public Assets

This directory contains static assets served at the root URL.

## Required Files

### OG Image (`og-image.png`)
- **Dimensions**: 1200x630 pixels (recommended for social media)
- **Format**: PNG or JPG
- **Purpose**: Social media preview image (Open Graph, Twitter Cards)
- **Content**: Should showcase the Colorblind Viewer tool with:
  - App name/logo
  - Brief tagline about accessibility testing
  - Visual representation of the tool
  - Brand colors (purple/blue gradient theme)

### Favicon (`favicon.ico`)
- Standard favicon for browser tabs

### Apple Touch Icon (`apple-touch-icon.png`)
- **Dimensions**: 180x180 pixels
- For iOS home screen icons

## Creating the OG Image

You can create the OG image using:
- Design tools (Figma, Canva, Photoshop)
- Online OG image generators
- Or use Next.js Image Generation API for dynamic OG images

The image should be visually appealing and clearly communicate what the tool does.
